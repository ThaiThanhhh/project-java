Attention Mechanism in Transformers

The attention mechanism allows the model to focus on different parts of the input sequence when producing each element of the output sequence. It computes a weighted sum of values, where the weights are determined by the compatibility of queries with keys.

Key Components:
  • Queries: What the model is looking for
  • Keys: What the input offers
  • Values: The actual content to be attended to
